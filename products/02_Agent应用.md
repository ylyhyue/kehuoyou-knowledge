# 客货邮融合 Agent 应用设计方案

## 定位

打造客货邮领域的“专家级智能助手”，把政策、标准、方案、评审能力封装为可对话、可执行、可追责的 Agent。

## 用户角色与 Agent 矩阵

| 角色 | 核心诉求 | 推荐 Agent |
|---|---|---|
| 政府工作人员 | 政策解读、方案审查、数据汇总 | 政策通、数据眼、评审官 |
| 企业运营人员 | 线路优化、运力调度、异常处理 | 冷链管家、数据眼 |
| 农户/合作社 | 农产品上行、冷藏仓租用、产销对接 | 冷链管家 |
| 标准化专家 | 编码合规、标准符合性审查 | 标准匠、评审官 |
| 咨询顾问 | 快速生成方案、培训材料 | 方案师、政策通 |

## Agent 详细设计

### 1. 政策通（Policy Assistant）

**能力**：
- 回答豫交规〔2025〕17号、平交文〔2026〕3号等政策问题
- 生成政策要点摘要
- 根据本地情况生成任务清单
- 提醒关键时间节点（如9月1日接入省平台）

**示例对话**：
- 用户：17号文对县级中心补助标准是什么？
- Agent：县级寄递公共配送中心新建补助比例不高于投资额的20%，提升改造不高于50%，且补助金额最高均为200万元。

### 2. 方案师（Solution Architect）

**能力**：
- 根据输入的县区资源、节点现状、产业特色生成客货邮融合实施方案
- 输出包含总体架构、业务流程、实施路径、投资测算的文档
- 支持多轮澄清需求

**输入**：
- 县区名称、人口、特色产业
- 现有节点数量与运营状态
- 客运/货运/邮政资源
- 预算与目标

**输出**：
- 实施方案 Markdown
- 关键指标表
- 任务分工表
- 风险清单

### 3. 标准匠（Standards Expert）

**能力**：
- 解释 GS1、SSCC、GLN、EPCIS 等标准
- 生成 SSCC 编码示例
- 检查标签/编码合规性
- 指导条码生成、识读、应用流程

### 4. 冷链管家（Cold Chain Manager）

**能力**：
- 设计移动冷藏仓布局方案
- 计算冷藏仓数量与覆盖半径
- 生成温控监测方案
- 提供农产品上行操作流程

### 5. 评审官（Review Officer）

**能力**：
- 对客货邮申报材料进行预评审
- 按政策文件和验收标准打分
- 指出缺项、弱项、风险点
- 生成评审意见

### 6. 数据眼（Data Monitor）

**能力**：
- 对接运行数据，生成监测报告
- 识别异常（超时、缺数据、低装载率）
- 输出可视化图表
- 支持绩效评价

## 技术架构

```
用户提问
   │
   ▼
意图识别 + 路由
   │
   ├── 政策问答 → RAG 检索政策库 → 生成回答
   ├── 方案生成 → 调用方案模板 + 用户输入 → 生成文档
   ├── 标准查询 → 检索标准库 + 编码工具 → 生成结果
   ├── 评审检查 → 读取材料 + 评审清单 → 生成意见
   └── 数据分析 → 调用数据接口 → 生成图表
```

## 知识库支撑

- 向量数据库：存储政策、标准、案例、方案的文本片段
- 结构化知识：节点、线路、指标、主体等实体关系
- 工具函数：编码生成、标签生成、计算模型

## 部署方式

1. **WorkBuddy 内置 Agent**：利用 WorkBuddy Agent 框架，直接调用。
2. **独立 Web 服务**：FastAPI/Flask + LLM + RAG，提供 API。
3. **网站嵌入**：在门户网站中提供 Agent 对话窗口。
