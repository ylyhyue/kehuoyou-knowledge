# 客货邮融合门户网站产品方案

## 产品定位

对外品牌窗口、知识发布平台、服务展示入口。

目标用户：
- 政府部门（省/市/县交通局、邮政管理局、农业农村局等）
- 企业（邮政、快递、客运、货运、冷链园区）
- 农户/合作社
- 标准化/评审专家
- 学习者/研究者

## 核心页面设计

### 首页

- 首屏：大标题 + 核心价值主张 + CTA（查看方案 / 联系咨询）
- 四大抓手卡片：一平台、一园区、一链条、一体系
- 数据亮点：6个县中心、84个乡镇站、2118个村级点、100个冷藏仓
- 最新动态：政策更新、试点进展、培训活动
- 合作伙伴：财投数智、华豫永新、政府部门

### 政策中心

- 政策卡片：标题、发文机关、文号、日期、摘要
- 标签筛选：国家/省/市、建设/运营/资金/验收/平台
- 解读文章：把政策要点转化为可执行动作
- 下载入口：原文 PDF/Word

### 标准体系

- 标准图谱：展示 GS1/SSCC/GLN/EPCIS 的关系
- 每个标准：定义、应用场景、编码示例、合规要点
- 工具入口：SSCC 编码生成器、标签模板下载

### 解决方案

每个解决方案一个独立页面：
- 问题背景
- 方案架构
- 核心能力
- 业务流程
- 预期成效
- 典型案例

### 数据看板

- 节点覆盖地图（中国地图，突出平顶山及六县）
- 线路运营统计
- 业务量趋势
- 绩效指标达成率
- 异常预警（需对接实际数据，初期可展示规划目标）

### 能力服务

- 服务内容、适用对象、交付形式、案例
- 在线咨询入口
- 培训认证报名

## 技术实现

### 推荐方案 A：静态站点（MVP 首选）

- 框架：Vite + React + Tailwind CSS
- 内容源：Markdown（放在 knowledge 仓库）
- 构建：GitHub Actions / 本地脚本
- 部署：CloudStudio / Vercel
- 优点：轻量、快速、成本低、易维护

### 推荐方案 B：Next.js 全栈

- 框架：Next.js + shadcn/ui
- 内容：SSG/ISR 渲染 Markdown
- 后端：可选接入数据库/向量库
- 部署：Vercel / 自有服务器
- 优点：SEO 好、可扩展性强

## 内容维护流程

```
更新 Markdown → Git 提交 → 自动构建 → 部署上线
```

所有内容保存在 `kehuoyou-knowledge/` 下，网站只是消费层。
