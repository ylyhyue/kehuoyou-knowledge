## 筑基期（2026.08 - 2026.09）

**目标**：建立知识库、完成首个网站和 Agent MVP。

**关键任务**：
1. ✅ 建立 `kehuoyou-knowledge/` 目录与内容规范
2. ✅ 提取 Office/PPT 原文到 `raw_extracts/`
3. ✅ 编写政策解读、迭代记录、架构蓝图
4. ⬜ 初始化 Git 仓库，配置 CI/CD 流水线
5. ⬜ 搭建静态网站骨架并部署
6. ⬜ 开发首个 Agent“政策通”并接入 WorkBuddy
7. ⬜ 封装首个 Skill“kehuoyou-policy”

**验收标准**：
- 网站可访问，展示首页、政策中心、标准体系、解决方案
- Agent 可回答 17 号文基本问题，准确率达 80%+
- Skill 可通过触发词调用

## 产品化期（2026.09 - 2026.11）

**目标**：完善产品矩阵，形成可对外服务能力。

**关键任务**：
1. 网站增加案例展厅、数据看板、能力服务页面
2. Agent 扩展为 4-6 个（政策通、方案师、标准匠、冷链管家）
3. Skill 扩展为 4-6 个（政策、标准、方案、PPT、冷链）
4. 建立向量知识库和知识图谱
5. 完成第一个对外培训课件（客货邮标准化专题）
6. 形成可复用的咨询/评审服务流程

**验收标准**：
- 网站内容完整，UV 达到内部推广目标
- Agent 可生成简单实施方案
- Skill 可在团队内共享使用

## 运营期（2026.11 - 2027.02）

**目标**：对接实际业务数据，验证产品价值。

**关键任务**：
1. 对接市级客货邮平台运行数据（脱敏）
2. 数据看板展示真实节点、线路、业务量
3. Agent 支持数据查询和绩效分析
4. 沉淀郏县、鲁山试点案例
5. 开展 2-3 场培训或评审服务
6. 持续优化 Skill 和 Agent 效果

**验收标准**：
- 数据看板有真实数据更新
- 形成 2 个以上可复制案例
- 完成至少 1 次对外服务交付

## 推广期（2027.02 以后）

**目标**：把“平顶山经验”对外输出，形成品牌影响力。

**关键任务**：
1. 申报省级/国家级标准化试点示范
2. 发布团体标准/地方标准草案
3. 把网站和 Agent 推广到其他地市
4. 建立培训认证体系（条码师、客货邮运营师等）
5. 探索 OPC（一人公司）商业模式

## 本期（2026.08）优先行动

1. **Git 初始化**
   - 在 `kehuoyou-knowledge/` 下初始化 Git
   - 创建 `.gitignore`，排除 `raw_extracts/` 中的大文件（可选）
   - 第一次 commit

2. **网站 MVP**
   - 选择 Vite + React + Tailwind 技术栈
   - 在 `kehuoyou-knowledge/site/` 下创建项目
   - 首页 + 政策中心 + 标准体系 + 解决方案

3. **Agent MVP**
   - 在 WorkBuddy 中创建“客货邮政策通”Agent
   - 导入 `policies/` 和 `iterations/` 内容
   - 测试 10 个常见问题

4. **Skill MVP**
   - 在 `~/.workbuddy/skills/kehuoyou-policy/` 下创建 SKILL.md
   - 实现政策查询脚本
   - 在 WorkBuddy 中测试调用

5. **CI/CD MVP**
   - 编写 `scripts/build_vector_index.py`
   - 配置 GitHub Actions 自动构建网站
   - 实现 Markdown → 网站的自动渲染

## 资源需求

| 资源 | 用途 | 建议 |
|---|---|---|
| 域名 | 网站访问 | 注册 `kehuoyou-pds.cn` 等 |
| 服务器/托管 | 网站部署 | CloudStudio 免费额度 |
| 向量库 | Agent RAG | Chroma 本地/免费云 |
| LLM API | Agent 推理 | 按需调用 |
| 人力 | 内容维护、产品开发 | 建议每周投入 4-8 小时 |

## 风险与应对

| 风险 | 应对 |
|---|---|
| 体制内时间精力有限 | 用 MVP 和自动化降低投入，优先做高价值模块 |
| 数据隐私合规 | 网站展示数据脱敏，运行数据不公开 |
| 技术栈变更 | 用 Markdown + Git 保持内容独立，降低耦合 |
| 知识产权归属 | 明确单位/个人作品边界，合规使用公开政策和通用标准 |
