## 五、一平台：市级客货邮融合服务平台

### 平台结构

围绕三件事：服务客户、组织业务、支撑监管。

| 维度 | 内容 |
|-|-|
| 服务客户 | 群众入口、企业运营端、司机/站点端、政府监管端 |
| 组织业务 | 订单受理、运力匹配、节点交接、仓配冷链、结算评价 |
| 支撑监管 | 线路、运力、站点、邮件快件数据汇聚、运行监测、分析报告 |

统一身份、数据授权、安全审计和稳定运行作为共同保障。

### 核心功能

四类使用对象、八项核心业务，功能随业务成熟度逐步启用：

| 对象 | 核心需求 |
|-|-|
| 政府 | 看运行、看服务、看安全 |
| 企业 | 接订单、调运力、做结算 |
| 司机/站点 | 领任务、做交接、报异常 |
| 城乡群众 | 购票、寄件、查询、反馈 |

八项核心业务：客户与主体、订单受理、运力与线路、调度与交接、仓配与冷链、费用与结算、运行监测、群众服务。

### 数据交换

市级平台连接六类协同对象：省级综合交通平台、县区平台与三级节点、邮政快递业务系统、客运与货运运营系统、园区仓配及冷链设备、定位扫码与交接终端。

接入原则：先接真实业务、先通关键数据、保留人工兜底、全过程留痕。

### 运营保障

人员、车辆、货物、数据和连续服务五条底线：

- 人员有责任
- 车辆有条件
- 货物有规则
- 数据有授权
- 服务有预案

## 七、一链条：标准化移动冷藏仓

### 标准化冷藏仓“四件套”

| 组件 | 说明 |
|-|-|
| 标准化周转箱 | 带SSCC条码+QR码，符合GB/T 29544 |
| 标准化循环共用托盘 | 参照GS1带板运输标准，一托一码 |
| 无线温控记录仪 | 全程温度自动采集上报，异常报警 |
| SSCC 18位物流单元编码 | GB/T 18127国标，全球唯一标识 |

### 从产地预冷到平台统管全链条

1. 产地预处理：田间采摘后即时入移动冷库预冷
2. 赋码装箱：标准化箱+托盘组合装载，贴附SSCC条码
3. 冷链配送：不换装/不断链运输，全程温控在线监测
4. 园区分拣：到园即扫，统仓共配，自动分拣至各流向
5. 平台统管：订单/运单/轨迹/结算四流合一，数据贯通

### 冷藏仓统筹管理模型

三种运营模式统一调配：

| 模式 | 特点 | 适用场景 |
|-|-|-|
| 直营模式 | 平台自建自营 | 高频量大的枢纽型点位 |
| 租赁模式 | 按需租用，平台统一投放 | 快速铺开 |
| 售卖模式 | 用户购买，平台统一调度 | 有实力的农户/合作社 |

关键机制：无论哪种模式，均需满足硬件标准化、编码统一、数据实时上传、接受平台统一调度。

## 八、一体系：平顶山市客货邮网融合体系

### 三大业务流程

#### 流程一：农产品上行

农户/合作社 → 乡镇服务站（组织集货与田间预冷、扫码入库） → 市级冷链园区（冷链中转与集中分拣） → 运力承运方（平台派单、车辆定位、温控上报） → 市场/商超/社区（验收签收、回传销量与结算信息）

#### 流程二：快件与工业品下行

品牌交仓 → 统一分拣 → 生成任务 → 客货协同（客运班车或货运车辆带货下行） → 节点接力 → 末端交付

结果数据回传省平台：村点出入库量、线路运输量、送达时效。

#### 流程三：客货邮车辆代运

平台汇聚待运快件 → 匹配班次与剩余载荷 → 生成装载清单 → 跟踪报警并结算

县级中心：安检、实名、封装、扫码交车  
客运企业：提交车辆班次、驾驶员确认、按线路运输、到站交接回传  
乡村节点：预约接货、核验封签、扫码入库、通知取件

**安全红线**：禁限带物品、客货隔离、装载重量与容积、车辆动态监控、报警信息清零。

### 体系绩效设计

| 指标层级 | 代表性指标 | 使用原则 |
|-|-|-|
| 政策任务 | 三级节点覆盖、融合线路建设、配送时效、业务量增长 | 按市级文件要求评价 |
| 平台运行指标 | 节点在线率、数据完整率、接口成功率、预警闭环率、故障恢复时长 | 可直接从系统取数 |
| 运营效率指标 | 准时交接率、车辆装载率、空驶里程、单位配送成本、结算周期 | 试点基线后签约 |
| 产业民生指标 | 冷链损耗率、农产品上行量、群众取件距离/时间、投诉满意度 | 按品类和县区评价 |
| 本地发展指标 | 资源接入度、业务协同度、设施利用率、经营可持续性、群众获得感 | 以平顶山基线测算 |

### 体系执行机制

**五张清单**：

1. 客户清单：目标客户、联系人、需求、推进状态
2. 货源清单：品类、货量、流向、频次、温层
3. 线路清单：节点、车辆、班次、成本、服务标准
4. 伙伴清单：邮政快递、承运、站点、园区和渠道
5. 问题清单：业务、安全、数据、结算与协调事项

**经营节奏**：

- 日常运营：订单、交接、异常、签收
- 周度经营复盘：商机、货源、线路、问题
- 月度运行分析：业务量、时效、成本、服务与安全

**责任分工**：

- 业务负责人：找客户和货源
- 运营负责人：跑线路和履约
- 平台团队：支撑数据与工具
- 县区协调：主体和节点

### 平台融合效应

- 业务拓展效应：客户、货源、线路与产品进入统一台账
- 运输组织效应：订单驱动车辆、班次、节点和线路协同
- 经营核算效应：服务量、收入、成本、结算和分配按业务单元留痕
- 产业协同效应：电子商务、特色农业与冷链产品形成组合服务链
- 群众服务效应：购票、寄件、跟踪、投诉及生活服务形成统一入口
- 治理监测效应：业务量、时效、安全、投诉和异常闭环形成监测分析

### 人、车、站、货、线动态协同

市级平台按时效、车型、载荷、方向和线路进行智能匹配，实现：

- 降低空驶率
- 减少无效里程
- 提升装载率
- 提高单车效率
- 畅通双向流通（工业品下乡 + 农产品进城）
