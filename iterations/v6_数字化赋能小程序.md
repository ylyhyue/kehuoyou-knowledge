## 二、小程序定位

### 2.1 目标用户

- **中小企业主**：想了解标准化、条码、营商环境政策的用户。
- **创业者/参赛者**：需要创业导师、赛事辅导、条码师培训的人。
- **政府/政务侧**：关注客货邮融合、营商环境监测、标准化试点的合作方。

### 2.2 核心价值

1. **品牌门户**：专家名片 + 服务入口 + 政策/标准资源聚合。
2. **智能咨询**：4 个咨询助手（条码师培训、营商数擎、满意标尺、创业问答）即时对话。
3. **咨询沉淀**：在线填写、飞书表单、腾讯文档三通道把咨询结构化沉淀到飞书多维表格。
4. **开放接口**：预留 `openApi` 云函数标准化共享接口，便于官网、政务系统等外部平台对接。

## 四、本次改造要点

### 4.1 品牌统一与合规措辞

- `app.json` 窗口标题：`数字化赋能`
- `project.config.json` 的 `projectname`：`数字化赋能`
- **智能体品牌统一为"咨询助手"**：面向用户的 Bot / AI / 智能体 / 博士团队 等字眼统一改为"咨询助手"（底部 tabBar、首页卡片、助手管理页、分享页、对话页 toast 同步）。专家本人"标准化博士团队"身份属事实性表述，保留不改。
- **规避 AI 字眼**：博士团队页去掉"点击分享本小程序"按钮，改为右上角 ··· 转发；全站不出现 bot / 人工智能等可能敏感措辞。
- 保留 `expert.wxml` 中"兼任省、市大众创业导师"的真实职务简介。

### 4.1.1 云函数密钥已迁移环境变量（2026-08-11）

- 早期云函数内硬编码的飞书 Secret / DeepSeek Key 已全部移除，改为读取 `process.env`（生产云端环境变量）+ 本地 gitignored `secrets.local.js`（调试兜底）双通道。
- 提供 `.env.example` 与 `secrets.local.example.js` 占位模板（已提交，不含真实密钥）。
- 密钥曾被明文暴露，建议到对应控制台**轮换**：飞书开放平台、DeepSeek 控制台；并撤销早期 GitHub PAT、改 Fine-grained PAT。

### 4.2 "数字赋能"页重构（2026-08-11 优化）

页面结构从上到下：

1. **橙色 banner**：数字化赋能企业高质量发展 + 副标题。
2. **两大抓手卡片**：标准化让企业"做对的事"，条码让企业"把事连上网"。
3. **标准化数字化赋能案例——数字交通**：平顶山客货邮融合项目（1 个团队 / 1 个实验室 / 1 个体系），商业化表述，导语不出现"均可点击链接"等口语；1 个体系三大子平台每项右侧加"点击查看 ›"提示。
4. **AI 条码实验室九大作业节点**：主页仅留简介 + "→ 查看九大作业节点"链接，点击进入 `pages/lab/lab` 子页（避免长页堆叠，页面更清爽）。
5. **条码数字化赋能案例——数字营商**：GS1、中国物品编码中心、营商环境监测平台、试点验收（"评审专家公示"）、团体标准、开源项目链接。
6. **资源入口（精简为两行）**：
   - 权威学习网站 / 国家标准化管理委员会（官网链接）
   - 条码师报考 / 培训指引 / 进入「我的」预约报名（跳预约填写页）
   - 删除了原蓝色"标准化数字化赋能"模块及其下属 4 个链接项（营商环境、中小企业标准化、政策解读、自评问卷）。

> 页面不显示任何网址，所有外链以友好文字呈现，真实地址保留在 `data-url`；未配置业务域名时由 `web` 页降级为"复制链接到浏览器"。

### 4.3 外链可打开

- 所有外部链接统一走 `pages/web/web`。
- 由于多数外部域名（github.io、gs1.org、ancc.org.cn、chbeo.org.cn 等）无法直接在微信 web-view 中打开（未加入业务域名），`web` 页提供兜底：
  - 空链接/非法链接提示。
  - `binderror` 触发后显示"复制链接到浏览器打开"。
