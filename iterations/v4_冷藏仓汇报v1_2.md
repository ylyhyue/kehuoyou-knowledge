## 六、一链条：标准化移动冷藏仓

### 核心理念

- 前置冷藏仓/移动仓：田间预冷 + 灵活仓储 + 上行集散
- 把冷链末梢下沉到村、到田间地头
- 扩大三级节点客货邮上行的毛细血管

### 标准化冷藏仓全链条实景

1. **产地预冷**：前置可移动冷藏仓，田间即时预冷保鲜
2. **赋码装箱**：SSCC统一编码，标准箱 + 标准托盘
3. **冷链配送**：不换装/不断链，全程温控记录
4. **园区分拣**：华豫冷链枢纽，统仓共配/到园即扫
5. **上行对接**：市区/全省平台，数据归集/可追溯

### 创新范式

对标成熟单元化体系：
- 集装箱：ISO 668 标准箱 + SSCC 编码
- 中欧班列：SSCC + EPCIS + 区块链
- 带板运输：托盘/周转箱循环共用、不换装交接

**冷藏仓核心理念**：借鉴集装箱“全球唯一标识 + 不换装交接 + 自动识别”三大原则，在产地端构建“标准化箱 + 标准化托盘 + SSCC 编码 + 温控记录”四位一体单元化体系。

## 七、GS1 标准体系

- **GS1**：全球性、中立的非营利国际标准组织
- **GTIN**：全球贸易项目编号，标识商品
- **GLN**：全球位置码，标识物理或法律位置
- **SSCC**：系列货运包装箱代码，标识物流单元
- **GIAI**：全球单个资产标识
- **GSRN**：全球服务关系编号

## 八、条码应用流程

1. 编码申请
2. 条码生成
3. 标签打印
4. 扫码识读
5. 数据入库
6. 业务应用（结算/盘点/追溯）
