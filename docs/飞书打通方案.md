# 飞书打通方案（知识库 ↔ 飞书三件套）

> 本方案定义「客货邮融合知识库」与飞书的打通方式。
> 同步策略：**飞书为主战场，GitHub 同步回流**。

---

## 一、连接前置（必须先在 WorkBuddy 完成）

在 **设置 → 连接器 → 飞书** 中开启并授权，确保以下能力可用：

| 能力 | 用途 | 对应连接器 Skill |
|---|---|---|
| 知识库 Wiki | 知识沉淀主站 | `lark-wiki` |
| 云文档 Docx | 单篇文档协作 | `lark-doc` |
| 多维表格 Bitable | 版本 / 指标看板 | `lark-base` |
| 群机器人 Webhook | 迭代通知 | 自建应用 Webhook |

同时需在 WorkBuddy 连接 **GitHub** 连接器（用于 `gh` 推送）。

## 四、群机器人（迭代通知）

在目标工作群添加「自定义机器人」，获取 Webhook 地址，配置到环境变量
`FEISHU_WEBHOOK`。每次有新的版本提交 / 飞书同步后，由 `scripts/notify_feishu.py`
推送卡片消息，内容包含：版本号、主题、GitHub 链接、飞书节点链接。

## 五、同步策略：飞书主，GitHub 同步

```
        ┌─────────────┐         edit          ┌──────────────┐
        │  飞书 WIKI   │ ───────────────────▶ │  飞书 Base    │
        │ (主战场)     │                       │ (看板)        │
        └──────┬──────┘                       └──────┬───────┘
               │ sync_from_feishu（定时/触发）        │
               ▼                                       │
        ┌─────────────┐         push                │
        │ 本地知识库   │ ───────────────────────────▶ │
        │  (md 源)     │                              │
        └──────┬──────┘                              │
               │ gh push                             ▼
               ▼                              ┌──────────────┐
        ┌─────────────┐                       │  GitHub 仓库  │
        │  GitHub 仓库 │ ◀──────────────────── │ (对外展示)    │
        │ (版本沉淀)   │   首次全量 / 飞书回流    └──────────────┘
        └─────────────┘
```

- **首次**：本地全量 → `gh push` 到 GitHub；本地全量 → `sync_to_feishu` 灌入飞书。
- **日常**：在飞书 WIKI / Base 编辑 → WorkBuddy automation 触发 `sync_from_feishu.py`
  把飞书最新内容拉回本地 md → `git commit` + `gh push` 回流 GitHub。
- **通知**：每次回流 / 新版本 → 群机器人卡片推送。

> 说明：飞书 → GitHub 的自动回流建议在 WorkBuddy 内用 **automation**（定时或事件触发）
> 承载，因为需要飞书连接器鉴权；GitHub Actions 无法直接访问飞书连接器。

---

## 六、连接后的执行清单

1. 用户在 WorkBuddy 连接 **GitHub** 与 **飞书**（含 wiki/doc/base/机器人权限）。
2. `gh` 推送本地知识库全量到 GitHub（`main` 分支）。
3. 运行 `scripts/sync_to_feishu.py` 初始化飞书 WIKI 节点 + 多维表格。
4. 配置群机器人 Webhook 到 `FEISHU_WEBHOOK`，验证 `notify_feishu.py`。
5. 创建 WorkBuddy automation：`sync_from_feishu` → `git commit` + `gh push`（飞书主同步回流）。
6. 每新增一版汇报：跑提取 → 写库 → 向量索引 → 同步飞书 → 群通知 → 回流 GitHub。
